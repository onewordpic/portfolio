### 2. Native macOS DNS Switcher 🍏📡
* **What it is:** A robust desktop utility application built directly in Xcode to manipulate system network configurations on the fly.
* **Key Features:** Seamlessly switch between security/ad-blocking providers (NextDNS, AdGuard), alongside a built-in cache-flushing tool.
* **Technical Depth:** Leverages native shell interfaces to safely run system-level utilities (`dscacheutil -flushcache` / `mDNSResponder`) and handles custom background system state management.
